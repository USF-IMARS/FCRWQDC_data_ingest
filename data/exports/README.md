Data in this directory generated from methods described here: usf-imars.github.io/FCRWQDC_data_ingest/.

A description of each of the files in this directory:


| File / Resource             | Description |
|-----------------------------|------------ |
| unified-wq-db-samples       | Analyte data aligned to FL DEP's analytics pipeline in 2025. |
| seasonal-mann-kendall-stats | Seasonality statistics aligned to FL DEP's analytics pipeline in 2025. |
| allData.csv                 | Aggregated data aligned to FL DEP's analytics pipeline in 2025. Values with Activity.Depth > 1 are not included in this dataset.|
| allData_wide.csv            | allData.csv transformed into "wide" format for easy ingest into some analytics pipelines. See usf-imars.github.io/FCRWQDC_data_ingest/tidy-wide.html |
| allDataRaw.csv              | The most comprehensive and least curated. This contains rows scraped from multiple sources and has had minimal cleaning applied. |
| allDataSEACAR.csv           | Data prepared for ingestion into the SEACAR database. See usf-imars.github.io/FCRWQDC_data_ingest/seacar-check.html |
| SEACAR Analyte CrossWalk    | A crosswalk from analyte names in source data to SEACAR standard names. |
| SEACAR program id mapping   | A mapping of Program Names/IDs to SEACAR standard names. |
